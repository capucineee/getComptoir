WooCommerce

Connecter votre boutique WooCommerce

WooCommerce n'a pas de plateforme centrale comme Shopify — chaque boutique est hébergée sur son propre WordPress. La connexion se fait donc par un webhook que vous configurez une fois, vous-même, dans votre admin WordPress. Pas besoin de développeur, mais comptez 5 minutes dans les réglages WooCommerce.

1

Générer vos identifiants dans Comptoir

Onglet Connecteurs → carte WooCommerce → Connecter → donnez un nom à votre boutique → Générer les identifiants. Comptoir affiche une URL de livraison et un secret, uniques à votre boutique — gardez cet écran ouvert pour l'étape suivante.

2

Créer le webhook dans WordPress

Dans votre admin WordPress : WooCommerce → Réglages → Avancé → Webhooks → Ajouter un webhook.

3

Remplir le formulaire

Nom libre (ex. « Comptoir »), Statut : Actif, Sujet : Commande créée, URL de livraison : collez celle de Comptoir, Secret : collez celui de Comptoir, Version de l'API : la plus récente proposée. Enregistrez.

4

Répétez pour les mises à jour (recommandé)

Ajoutez un second webhook identique avec le sujet Commande mise à jour — sans lui, Comptoir voit vos nouvelles commandes mais pas les changements de statut (expédiée, remboursée...) qui arrivent après coup.

WooCommerce envoie un test de connexion (« ping ») dès l'enregistrement du webhook — c'est normal, Comptoir le reçoit et ne crée aucune commande à partir de ça.

01Ce qui se synchronise

À chaque commande créée ou mise à jour sur WooCommerce, Comptoir reçoit l'information et met à jour la commande correspondante — y compris si son statut change plusieurs fois.

livree
commande « Terminée » sur WooCommerce
preparation
commande « En attente » ou « En cours »
retour
commande « Remboursée » ou « Annulée »

Le stock de vos produits dans Comptoir est ajusté automatiquement à chaque changement : une commande terminée le fait baisser, un remboursement le fait remonter.

02Votre forfait

Connecter WooCommerce compte comme un canal de vente sur votre forfait. Le nombre de commandes reçues via WooCommerce compte dans votre quota mensuel de commandes.

03Se déconnecter

DepuisEffet
Comptoir — Connecteurs → DéconnecterComptoir arrête d'accepter les commandes de cette boutique
WordPress — supprimez le(s) webhook(s)WooCommerce arrête d'envoyer — faites les deux pour une coupure complète
Le secret n'est affiché qu'une seule fois par Comptoir. Si vous le perdez, déconnectez ce connecteur et recommencez — inutile de chercher à le retrouver.
